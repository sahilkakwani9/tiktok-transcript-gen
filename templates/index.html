TikTok Monitor API

Use the following endpoints to monitor TikTok users for specific topics.

Start Monitoring (Cron Job)

POST /api/monitor

{
  "handle": "username",
  "start_date": "YYYY-MM-DD",
  "end_date": "YYYY-MM-DD",
  "topics": ["topic1", "topic2", "topic3"],
  "interval_seconds": 3600  /* How often to run the job (in seconds) */
}

Returns a task ID that can be used to check the status. If interval_seconds is provided, creates a recurring job.

Check Task Status

GET /api/task/<task_id>

Returns the current status and results if available.

Stop a Scheduled Task

POST /api/task/<task_id>/stop

Stops a running scheduled task.

List All Tasks

GET /api/tasks

Returns all tasks and their statuses.
